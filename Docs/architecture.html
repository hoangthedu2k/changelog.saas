Luồng người dùng chính
✍️ Đăng & publish changelog
1User đăng nhập Dashboard (Angular)
2Viết entry bằng rich text editor (Quill)
3Chọn tag: New / Fix / Improvement
4POST /api/entries → ChangelogService lưu DB
5Hangfire queue → gửi email cho subscribers
6Redis cache widget HTML được clear
🔔 Widget hiển thị trên app khách
1App khách load script: cdn.yourapp.com/widget.js
2Widget gọi GET /api/widget/{projectSlug}
3Redis trả cache HTML (< 10ms)
4Hiển thị badge "3 updates mới"
5User click → popup danh sách changelog
💳 Đăng ký trả phí
1User chọn plan trên Billing page
2Redirect sang Stripe Checkout
3Stripe gửi webhook → BillingService
4DB cập nhật subscription plan
5Unlock tính năng premium ngay lập tức
📧 Subscribe nhận email
1Visitor vào public changelog page
2Nhập email vào form subscribe
3POST /api/subscribers → gửi confirm email
4Click confirm link → status = verified
5Nhận email mỗi khi có update mới

Quan hệ giữa các bảng
users ──1──▶──N── projects 1:N 1 user có nhiều projects (sản phẩm)
projects ──1──▶──N── changelog_entries 1:N 1 project có nhiều entries (bản cập nhật)
projects ──1──▶──N── subscribers 1:N 1 project có nhiều subscriber
users ──1──▶──1── subscriptions 1:1 1 user có 1 gói Stripe subscription
changelog_entries ──1──▶──N── email_logs 1:N 1 entry → nhiều email gửi cho từng subscriber
SQL mẫu — tạo bảng chính
-- Tạo bảng projects
CREATE TABLE projects (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name            VARCHAR(100) NOT NULL,
  slug            VARCHAR(100) NOT NULL UNIQUE,
  custom_domain   VARCHAR(255),
  accent_color    VARCHAR(7) DEFAULT '#6366f1',
  is_public       BOOLEAN DEFAULT true,
  created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- Tạo bảng changelog_entries
CREATE TABLE changelog_entries (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id      UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
  title           VARCHAR(255) NOT NULL,
  content_html    TEXT,
  tags            TEXT[],
  status          VARCHAR(20) DEFAULT 'draft',
  version         VARCHAR(20),
  published_at    TIMESTAMPTZ,
  email_sent_at   TIMESTAMPTZ,
  created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- Index quan trọng
CREATE INDEX idx_entries_project ON changelog_entries(project_id, published_at DESC);
CREATE INDEX idx_subscribers_project ON subscribers(project_id, status);

POST/api/auth/refreshRefresh access token
POST/api/auth/logoutInvalidate refresh token
Projects endpoints
GET/api/projectsDanh sách projects của user
POST/api/projectsTạo project mới
GET/api/projects/{id}Chi tiết 1 project
PUT/api/projects/{id}Cập nhật settings project
DEL/api/projects/{id}Xóa project
Changelog entries endpoints
GET/api/projects/{id}/entriesDanh sách entries (phân trang)
POST/api/projects/{id}/entriesTạo entry mới (draft)
PUT/api/entries/{id}Cập nhật nội dung entry
POST/api/entries/{id}/publishPublish + gửi email subscribers
DEL/api/entries/{id}Xóa entry
Public endpoints (không cần auth)

GET/api/widget/{slug}Lấy data cho embed widget (cached)

GET/api/unsubscribe/{token}Hủy subscribe qua link email
GET/api/confirm/{token}Xác nhận email subscriber
